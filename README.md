## 🚀 Featured Builds

These are deployed, end-to-end systems — not just model training notebooks.

### 🗣️ [Agentic AI Call Evaluation System](https://github.com/pridwimnjha/-JustDial-Call-Evaluator)
Evaluates Hinglish customer call recordings end-to-end: transcription + speaker diarization (AssemblyAI) → custom Hinglish transliteration layer (70+ character mapping rules) → LLM-based scoring with Groq LLaMA 3.3 70B in JSON mode → 6-sheet color-coded Excel report. Includes a hallucination guard on model outputs.
`AssemblyAI` `Groq · LLaMA 3.3 70B` `Hinglish NLP` `Streamlit`

### 🖼️ [JD Magic Box — Media Moderation Hub](https://github.com/pridwimnjha/MediaModerationHub-JD-Magic-Box-v2)
Streamlit moderation tool classifying business listing images and videos as GO / NO-GO across four review modes, combining EasyOCR text extraction with multimodal LLM judgment (Gemini).
`EasyOCR` `Gemini API` `Streamlit` `Content Moderation`

### 🏷️ [Individual vs. Institution Classifier](https://github.com/pridwimnjha/-Individual_vs_Institution_Classifier)
3-layer hybrid classification system for tagging business listings by entity type, built without labeled training data: rule-based matching → BERT zero-shot NLI (cross-encoder/nli-MiniLM2-L6-H768) → TF-IDF fallback.
`BERT Zero-Shot NLI` `TF-IDF` `Hybrid Classification`
